# docs.go-docker

Public documentation for [gomatic/go-docker](https://github.com/gomatic/go-docker) — a stdlib-only Go client for the Docker Engine REST API. Published at [gomatic.github.io/docs.go-docker](https://gomatic.github.io/docs.go-docker/) via GitHub Pages when public.

User docs live in [content/](content/); contributor docs in [dev/](dev/). Run `make` for local preview targets.
